# UPSTDC Project Monitoring - Database (MongoDB)

This container hosts the MongoDB database for the UPSTDC Project Monitoring System.

Contents:
- schema/collections.json: Canonical collection definitions and indexes.
- seed/seed_data.json: Initial roles, admin user, and sample project data.
- scripts/init_db.js: Initialization script to create collections, enforce indexes, and seed data.
- backup_db.sh and restore_db.sh: MongoDB backup/restore scripts using standardized env variables.
- db_visualizer/: Simple database viewer helper (optional).

Environment variables
- MONGODB_URL: MongoDB connection string including credentials and host/port.
  Example: mongodb://appuser:dbuser123@localhost:5000/?authSource=admin
- MONGODB_DB: Database name (default: myapp)

Startup
- The startup.sh script:
  1) Uses MONGODB_URL and MONGODB_DB (with local defaults if not provided)
  2) Starts mongod on the host/port derived from the URL (localhost:5000 by default)
  3) Creates an admin user (from MONGODB_URL credentials) and least-privilege app user (readWrite on MONGODB_DB)
  4) Runs scripts/init_db.js to:
     - Create all required indexes:
       - users.email unique
       - projects.code unique
       - milestones.projectId
       - progress_logs.projectId+date
       - payments.projectId+date
       - documents.projectId
       - reports.projectId+generatedAt
       - audit_logs entity/actor indexes
     - Seed base data from seed/seed_data.json
  5) Writes a connection helper to db_connection.txt
  6) Writes db_visualizer/mongodb.env with MONGODB_URL and MONGODB_DB

How to initialize
- Option A (defaults):
  cd upstdc_database
  ./startup.sh
- Option B (custom URL/DB):
  export MONGODB_URL="mongodb://appuser:dbuser123@localhost:6000/?authSource=admin"
  export MONGODB_DB="myapp_dev"
  ./startup.sh

How to back up
- From the upstdc_database directory:
  ./backup_db.sh
- Produces database_backup.archive for MongoDB using MONGODB_URL and MONGODB_DB.

How to restore
- Place a valid database_backup.archive in the same directory.
- Run:
  ./restore_db.sh
- The script uses MONGODB_URL and MONGODB_DB to restore.

Schema overview
- Collections:
  users, roles, projects, milestones, progress_logs, documents, payments, reports, audit_logs
- See schema/collections.json for field descriptions and index definitions.

Security notes
- The init script uses the admin account only for creating collections and indexes.
- Data seeding is performed using the least-privilege app user (readWrite on the application DB).

Troubleshooting
- Ensure mongosh and mongod are available.
- Default local port is 5000 unless overridden by MONGODB_URL.
- The DB visualizer starts automatically on port 3020 during startup.sh and the script waits until it is ready.
  - Visualizer uses MONGODB_URL and MONGODB_DB from db_visualizer/mongodb.env.
  - Access: http://localhost:3020/
- Connection hint:
  mongosh "mongodb://appuser:dbuser123@localhost:5000/?authSource=adminmyapp"
  or see db_connection.txt generated by startup.sh
